# Change your dashboard language

Change the EasyWebinar dashboard language from the flag button in the top bar or from My Profile, find a language by search or its own name, and check the result.

- Applies to: The EasyWebinar dashboard
- Status: Live
- Verified: 2026-10-27
- Canonical page: https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/account/dashboard-language/

The dashboard language is the EasyWebinar setting for your dashboard's language, from 11 languages. Click the round flag button in the top bar, then click a language. It switches at once, with no **Save** button. The same setting is under **Settings → My Profile → General Settings → Language**.

**Expected result:** the sidebar, top bar and main dashboard pages show in the language you picked, and stay that way after a reload.

## At a glance {#at-a-glance}

| | |
|---|---|
| **Where** | The flag button in the top bar, or **Settings** → **My Profile** → **General Settings** → **Language** |
| **How you change it** | Click a language in the list. There is no **Save** button |
| **Languages** | 11, listed under **AVAILABLE LANGUAGES · 11** |
| **When it applies** | At once, and it stays after a reload and as you move between pages |
| **Finding a language** | Type in **Search languages…**, or read each language's own name |
| **What changes** | The dashboard interface, such as the sidebar, top bar, Home, Settings, Library and Integrations |
| **What stays as it is** | Your own content, brand and integration names, your plan's name and each language's own name |
| **Related setting** | [Webinar Language](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/webinars/setup/webinar-language/#at-a-glance), the default language for attendees, set on each webinar |
| **EasyCRM** | Uses the same language. Change it in either app and the other follows: [Change your EasyCRM language](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/account/easycrm-language/) |

## Before you begin {#before-you-begin}

- **Sign in to the dashboard.** You change the dashboard language while signed in to EasyWebinar.
- **Pick the right setting.** The dashboard language changes the screens you work in. To set the default language for attendees, use [Webinar Language](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/webinars/setup/webinar-language/) on the webinar instead.
- **Expect your own content to stay as it is.** Your content, brand and integration names don't change.
- **Know each language's own name.** Every entry shows it on a second line, so you can find your language in any menu language.

You can reach the dashboard language in two ways. Use the flag button in the top bar and pick a language, or go to **Settings** → **My Profile** → **General Settings** → **Language**. Both routes reach the same setting, with the same 11 languages, and the change applies at once.

## What the dashboard language is {#what-it-is}

The dashboard language is the EasyWebinar setting for the language of the dashboard interface, chosen from 11 languages. Its helper text says it *Applies to the dashboard interface.* It changes the screens you work in, such as the sidebar, Home, Settings and Library.

The dashboard language is separate from **Webinar Language**, which sits on each webinar's **Settings** tab. Webinar Language sets the default language attendees get when they join. **Date Display Language** is another separate field on the webinar. The table and diagram below set the two language settings side by side.

| | Dashboard language | Webinar Language |
|---|---|---|
| **Where you set it** | The flag button in the top bar, or **Settings → My Profile → General Settings → Language** | The webinar's **Settings** tab → **General** → **Webinar Language** |
| **Who sets it** | You, while signed in to the dashboard | The host |
| **What it changes** | The dashboard interface, such as the sidebar, top bar, Home, Settings, Library and Integrations | The default language attendees get when they join |
| **Applies to** | The EasyWebinar dashboard | Live webinars |
| **Languages** | 11 | The same 11 |
| **When it takes effect** | At once, with no **Save** button | When you click **Save Changes** |
| **What stays the same** | Your own content, brand and integration names | Your own titles and text: it sets the interface default, not your content |

![Diagram comparing dashboard language and Webinar Language: where each is set, who sets it and what it applies to](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/images/dashboard-language/diagram-01-dashboard-vs-webinar-language.svg)

*Dashboard language changes your dashboard. Webinar Language sets the default for attendees.*

## Why the dashboard language matters {#why-it-matters}

### What it's for {#what-its-for}

The dashboard language lets you work in EasyWebinar's menus and settings in a language you read well. You change it from the top bar with two clicks. Nothing needs saving.

### How it helps {#how-it-helps}

- **Settings read in your language.** Labels such as **Configuración general** and **Idioma** appear in the language you chose.
- **No save step.** The dashboard language applies the moment you click, with no **Save** button.
- **Easy to undo.** Each language shows its own name, so you can find **English** again from any language.
- **Your content stays put.** Your own content, brand and integration names stay as they are.

### What happens without it {#without-it}

Without a dashboard language setting, everyone reads the same menu language. Someone who reads Spanish or Japanese more easily works through English settings more slowly.

### Why buyers care {#why-buyers-care}

The dashboard language matters most when the people who build webinars read another language more easily than English. The list holds 11 languages, and Italian isn't one of them. Check the list under Step 2 before you rely on a language.

## The EasyWebinar approach to the dashboard language {#approach}

{/* 5P */}

Take a typical case. A small team runs webinars for coaches. Its next webinar is for coaches in Brazil, so it runs in Portuguese. The team works in English and keeps its own dashboard in English.

A common approach is to assume one language switch covers everything. Someone changes the dashboard to Portuguese to prepare the webinar. The team then works through menus it reads less easily.

The problem sits in mixing up two questions. The language the team works in and the language attendees get are separate settings.

EasyWebinar keeps them apart. The dashboard stays in English, set with the flag button or under **Settings → My Profile → General Settings → Language**. On the webinar, the host sets **Webinar Language** to **Portuguese (Brazil)** on the **Settings** tab → **General**. That happens without entering the live room.

The language list pictured under Step 1 is headed **AVAILABLE LANGUAGES · 11**. The end of the list, pictured under Step 2, shows **Portuguese (Brazil)** with *Português (Brasil)* underneath. How other platforms handle dashboard languages is covered in How the dashboard language compares, below.

## Limits and things to know {#limits}

- **There are 11 languages.** Italian isn't one of them.
- **Your own content isn't translated.** Your content, brand and integration names, your plan's name and each language's own name stay as they are.
- **Team join dates keep their format.** The date format on the Team screen's join dates doesn't change.
- **There is no per-member language column.** The Team screen doesn't show a language for each member.
- **It doesn't set the language for attendees.** That default comes from each webinar's **Webinar Language**.

## Common questions {#common-questions}

#### How do I change the language of my EasyWebinar dashboard? {#faq-how}

Click the round flag button in the EasyWebinar top bar, then click a language. You can also go to **Settings → My Profile → General Settings → Language**.

#### Do I need to click Save after changing the dashboard language? {#faq-save}

No. The EasyWebinar dashboard language applies as soon as you click a language, and there is no **Save** button.

#### Does the dashboard language stay after I reload the page? {#faq-reload}

Yes. The EasyWebinar dashboard keeps the language you chose after a reload and as you move between pages.

#### Which languages can the EasyWebinar dashboard use? {#faq-which}

The EasyWebinar dashboard has 11 languages. They are English, Spanish, Japanese, French, German, Portuguese (Brazil), Chinese (Simplified), Korean, Hindi, Danish and Arabic.

#### Is Italian available as a dashboard language? {#faq-italian}

No. Italian isn't one of the 11 languages in the EasyWebinar dashboard.

#### How do I get back to English if I can't read the menus? {#faq-switch-back}

Open the flag button in the EasyWebinar top bar and look for **English** on the second line of an entry. In a Spanish dashboard it's the first entry, *Inglés*.

#### Can I search for a dashboard language? {#faq-search}

Yes. Type in **Search languages…** at the top of the EasyWebinar language list. Typing *Ja* leaves only Japanese.

#### Does the dashboard language translate my own content? {#faq-content}

No. In EasyWebinar, your own content, brand and integration names and your plan's name stay as they are.

#### Does the dashboard language set the language my attendees get? {#faq-attendees}

No. The EasyWebinar dashboard language *Applies to the dashboard interface.* The default for attendees is set on each webinar with **Webinar Language**.

#### Does the Team screen show each member's language? {#faq-team-column}

No. The EasyWebinar **Team** screen has no per-member language column.

#### Do integration names change when I switch the dashboard language? {#faq-integrations}

No. On the EasyWebinar **Integrations** page, names such as Keap, HubSpot and EasyCRM stay as they are.

#### Is the language list itself translated? {#faq-list-language}

Yes. In Spanish, the EasyWebinar list heading reads **IDIOMAS DISPONIBLES · 11** and the search box reads **Buscar idiomas…**. Each language's own name stays the same.
