# Set the webinar language for attendees

Set a live webinar's Webinar Language from its Settings tab, choose from 11 languages by search or own name, and tell it apart from your dashboard language and Date Display Language.

- Applies to: Live webinars
- Status: Live
- Verified: 2026-10-27
- Canonical page: https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/webinars/setup/webinar-language/

Webinar Language is the EasyWebinar setting that picks the default language attendees get, from 11 languages. Open the webinar's **Settings** tab, stay on **General** and pick a language under **Webinar Language**. Then click **Save Changes**. You never need to enter the live room.

**Expected result:** the **Webinar Language** field shows your choice, such as *Spanish · Español*, and keeps it after a reload.

## Before you begin {#before-you-begin}

- **Open a live webinar.** This page covers live webinars. If you don't have one yet, start with [Create and schedule a live webinar](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/webinars/getting-started/create-a-live-webinar/#open-create-dialog).
- **Stay out of the room.** You set Webinar Language from the webinar's settings, without entering the live room.
- **Write your own text in the language you want.** Webinar Language sets the interface default, not your content. Your titles and page text stay as you wrote them.
- **Know which setting you need.** Your dashboard language is a separate setting that *Applies to the dashboard interface.* [Change your dashboard language](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/account/dashboard-language/) covers it.

## What Webinar Language is {#what-it-is}

Webinar Language is the EasyWebinar setting for the default language attendees get when they join a webinar. The host chooses it from the webinar's settings, without entering the live room. The list holds 11 languages.

The info icon beside **Webinar Language** opens a note headed *What does this change?* It says the setting picks "the language attendees see in supported webinar pages and interface text". It adds that it "does not translate spoken audio or uploaded videos". It also says "Exact coverage depends on your webinar configuration."

![The Webinar Language info note, What does this change?, open on a live webinar's General settings](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/images/webinar-language/step-04-what-does-this-change.png)

*1 What does this change?*

Webinar Language is separate from your dashboard language, whose helper text reads *Applies to the dashboard interface.* **Date Display Language** is another separate field, in the **Date & Time Display** section. Each one is set on its own. The table and diagram below set the two language settings side by side, and [Change your dashboard language](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/account/dashboard-language/#what-it-is) covers the other one.

| | Dashboard language | Webinar Language |
|---|---|---|
| **Where you set it** | The flag button in the top bar, or **Settings → My Profile → General Settings → Language** | The webinar's **Settings** tab → **General** → **Webinar Language** |
| **Who sets it** | You, while signed in to the dashboard | The host |
| **What it changes** | The dashboard interface, such as the sidebar, top bar, Home, Settings, Library and Integrations | The default language attendees get when they join |
| **Applies to** | The EasyWebinar dashboard | Live webinars |
| **Languages** | 11 | The same 11 |
| **When it takes effect** | At once, with no **Save** button | When you click **Save Changes** |
| **What stays the same** | Your own content, brand and integration names | Your own titles and text: it sets the interface default, not your content |
| **Next to it** | **Theme**, a separate field | **Date Display Language**, a separate field |

![Diagram comparing dashboard language and Webinar Language: where each is set, who sets it and what it applies to](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/images/webinar-language/diagram-01-dashboard-vs-webinar-language.svg)

## Why Webinar Language matters {#why-it-matters}

### What it's for {#what-its-for}

Webinar Language gives a webinar its own default language for attendees. You set it once, from the webinar's settings, before the session.

### How it helps {#how-it-helps}

- **Set on each webinar.** Webinar Language sits on each webinar's own **Settings** tab.
- **No trip into the room.** You choose Webinar Language from the webinar's settings, without entering the live room.
- **Your dashboard stays as it is.** Your dashboard language is a separate setting under **My Profile**.
- **Languages are easy to spot.** The Webinar Language list shows each language's own name underneath its English name.

### What happens without it {#without-it}

Without a setting on the webinar, the attendee default would need sorting out somewhere else. Setting it close to the session is easy to forget.

### Why buyers care {#why-buyers-care}

Webinar Language matters to teams that run webinars for audiences outside their own language. A webinar for coaches in Brazil, run in Portuguese, is one example. Both language settings offer the same 11 languages, so a host can work in the language the audience gets. Buyers comparing platforms should also read the Compare section below, which notes where rivals document more.

## The EasyWebinar approach to Webinar Language {#approach}

{/* 5P */}

Take a typical case. A small team runs webinars for coaches. Its next webinar is for coaches in Brazil, so it runs in Portuguese. The team works in English and keeps its own dashboard in English.

A common approach is to leave the language until the day of the session. Someone then has to remember it while also checking the camera, the slides and the guest speaker.

The problem sits in timing. A setting left to the last minute is easy to miss, and the team's own dashboard language is a separate question.

EasyWebinar puts the setting on the webinar's **Settings** tab. The host opens **General**, picks **Portuguese (Brazil)** under **Webinar Language** and clicks **Save Changes**. That happens without entering the live room. The team's dashboard stays in English, under **Settings → My Profile → General Settings → Language**. The team writes its titles and page text in Portuguese, because Webinar Language sets the interface default, not the content.

## Limits and things to know {#limits}

- **This page covers live webinars.** It describes Webinar Language as it appears on a live webinar's **Settings** tab.
- **There are 11 languages.** Italian isn't one of them.
- **Your own content isn't translated.** Webinar Language sets the interface default, not your titles, page text or the emails you write.
- **Date Display Language is a separate field.** It sits in **Date & Time Display** and is set on its own.
- **It doesn't translate audio or video.** The app's own note says Webinar Language "does not translate spoken audio or uploaded videos".
- **Coverage depends on the webinar.** The same note says exact coverage depends on your webinar configuration.
- **Nothing is kept until you save.** Click **Save Changes** before you leave the page.
- **It isn't your dashboard language.** That's a separate setting under **My Profile**.
- **The default is English.** A new live webinar's **Webinar Language** shows English.

## Common questions {#common-questions}

#### Where do I set the webinar language in EasyWebinar? {#faq-where}

On the webinar's **Settings** tab → **General** → **Webinar Language**. Open the webinar from **My Webinars** first.

#### Do I need to enter the live room to set the webinar language? {#faq-live-room}

No. In EasyWebinar, the host sets Webinar Language from the webinar's settings, without entering the live room.

#### What does Webinar Language set? {#faq-what-it-sets}

EasyWebinar's Webinar Language sets the default language attendees get when they join. It sets the interface default, not your own content.

#### How many languages does Webinar Language offer? {#faq-how-many}

EasyWebinar's Webinar Language list is headed **AVAILABLE LANGUAGES · 11**. The 11 are English, Spanish, Japanese, French, German, Portuguese (Brazil), Chinese (Simplified), Korean, Hindi, Danish and Arabic.

#### Is Italian available as a webinar language? {#faq-italian}

No. Italian isn't one of the 11 languages in EasyWebinar's Webinar Language list.

#### What is the default webinar language? {#faq-default}

English. A live webinar's **Webinar Language** field in EasyWebinar shows English by default.

#### Is Webinar Language the same as my dashboard language? {#faq-dashboard}

No. Your EasyWebinar dashboard language *Applies to the dashboard interface* and lives under **My Profile**. [Webinar Language](https://maximuslabs-ai.github.io/easywebinar-product-docs/product-docs/account/dashboard-language/#with-webinar-language) is set on each webinar.

#### Is Date Display Language the same as Webinar Language? {#faq-date-display}

No. **Date Display Language** is a separate field next to **Webinar Language** on EasyWebinar's **General** settings, and you set it on its own.

#### Will Webinar Language translate my webinar title and page text? {#faq-own-content}

No. EasyWebinar's Webinar Language sets the interface default for attendees, not your content. Your titles and page text stay as you wrote them.

#### Does each webinar have its own language? {#faq-per-webinar}

Yes. EasyWebinar's Webinar Language sits on each webinar's own **Settings** tab, so you set it per webinar.

#### Do I need to click Save Changes after choosing a webinar language? {#faq-save}

Yes. EasyWebinar keeps Webinar Language only after you click **Save Changes** on the **General** sub-tab. The app then shows *General settings saved successfully.*

#### Which settings sit next to Webinar Language? {#faq-nearby-settings}

On EasyWebinar's **General** sub-tab, **Webinar Language** has its own section. **Date & Time Display** sits above it and **Attendee Experience & Redirects** below.
