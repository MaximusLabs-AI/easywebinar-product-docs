# Limits and defaults

Every limit, allowance and default setting in EasyWebinar in one place, with its unit and where it applies.

- Applies to: All plans unless a row says otherwise
- Status: Live
- Verified: 2026-10-16
- Canonical page: https://maximuslabs-ai.github.io/easywebinar-product-docs/easywebinar-product-docs/product-docs/reference/limits-and-defaults/

Use this page to check a number before you plan a webinar. Each row names the unit and where the limit applies. Prices are not listed here; see the live pricing page for current prices.

## Attendee capacity by plan {#attendee-capacity}

| Plan | Live attendees | Automated attendees |
|---|---|---|
| **Launch** | 50 | Not listed |
| **Growth** | 200 | 1,000 |
| **Pro** | 500 | 2,500 |
| **Scale** | 1,000 | 5,000 |

Capacities as shown in the plan chooser. Plans are billed monthly or yearly. The **Plan** tab under **Settings** meters live attendees, automated attendees and storage.

## Webinars and scheduling {#webinars-and-scheduling}

| Item | Value | Notes |
|---|---|---|
| Webinar type | Fixed after creation | Clone the webinar to change it |
| Default webinar type | **Live Webinar** | |
| Default schedule frequency | **Specific Date** | Also **Daily** or **Weekly** |
| Default timezone | Your account timezone | |
| Default schedule preference | Show only the next available session | |
| Past sessions | Can't be scheduled | Past dates are disabled |
| Just-in-time interval | 2, 15, 30, 45 or 60 minutes | Evergreen webinars only |
| Sessions in the attendee's local time | Just-in-time sessions only | Live and scheduled sessions use the webinar's timezone |
| Webinars live at once | One | Starting another shows "You can only have one event live at a time." |

## Registration and selling {#registration-and-selling}

| Item | Value | Notes |
|---|---|---|
| Default pricing | **Free** | Choose **Paid** at creation |
| Price currency | US dollars | Stripe may show local currency to attendees outside the US |
| Payment processor | Stripe | Payouts go to your own Stripe account |
| Default registration fields | Full name, Email | Both required; add custom fields |
| Registration templates | 17 templates, plus your own under **My Templates** | Filter by Agency, Coach, Education, Health & Wellness, Lead Magnet or Marketing |
| Polls per webinar | No practical limit | |

## AI credits {#ai-credits}

**Create with AI** uses credits, shown at the top right of every step.

| Part generated | Credits |
|---|---|
| Script | 10 |
| Landing pages | 10 |
| Emails | 1 |
| Polls | 1 |
| Offers | 1 |
| **Full build** | **About 23** |

A full build takes about ten minutes.

## EasyCRM sending allowance {#easycrm-allowance}

| Channel | Included each month |
|---|---|
| Emails | 1,000 |
| SMS | 100 messages |
| Call minutes | 100 |

The allowance resets on your **signup date**, not the first of the month. Broadcasts and workflows draw on the same allowance, and each channel is counted separately.

## Team and account {#team-and-account}

| Item | Value | Notes |
|---|---|---|
| Roles | Owner, Admin, User | One Owner per account |
| Team seats | Depend on your plan | Settings overview shows seats used |
| Client workspaces | Each on its own plan | Workspaces don't use team seats |
| Integrations | Set per webinar | Connecting one webinar doesn't connect the others |

## Add-ons {#add-ons}

| Add-on | What it unlocks |
|---|---|
